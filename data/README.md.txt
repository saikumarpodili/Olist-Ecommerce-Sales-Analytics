# Dataset Information

Dataset: Brazilian E-Commerce Public Dataset by Olist

Source: Kaggle

Tables Used:
- orders
- customers
- order_items
- products
- payments
- reviews
- sellers
- product_category_name_translation

Note:
The original dataset contains approximately 100K orders.
The geolocation dataset was not included in the project analysis due to its large size.

The dataset is used for SQL analysis, Python EDA, and Power BI dashboard development.
